# Harper & Ellie Mae Christmas — Working GitHub Pages Version

IMPORTANT: upload the **contents of this folder**, not the ZIP file itself.

The repository root must contain:
- index.html
- .nojekyll

The site is intentionally a single HTML file so CSS and JavaScript cannot be lost because of a wrong folder path.

## GitHub Pages
Repository → Settings → Pages → Deploy from a branch → main → / (root) → Save.

Then visit the repository's Pages URL.

## Features
- Four-corner opening animation
- Real Christmas photo feeds
- Live Christmas countdown
- Working hamper slideshow
- Santa's helpers section
- Santa flight animation through the page
- HO HO HO speech bubble
- Browser voice for Santa after the user clicks "Hear Santa"
- Animated Christmas train
- Personal Santa letter

## Important
The photos are loaded from LoremFlickr at runtime. This means the GitHub site needs internet access for the photographs. If a photo provider is blocked, the rest of the site still loads.
